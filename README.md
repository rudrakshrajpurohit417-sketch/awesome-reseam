## ℹ️ About

Awesome Reseam is an independent community directory. It is not affiliated with or endorsed by Reseam. Patch and release details link back to their publishers. This project does not host APKs or patch bundle files.

The catalog design was inspired by [Awesome Morphe](https://github.com/nvbangg/awesome-morphe). See [`LICENSE.awesome-morphe`](LICENSE.awesome-morphe) for its MIT notice.
